# JATI — Prototipe Frontend

Angular 19 + Tailwind CSS — fokus **PSN Jumantik** dan **Operasional PPSU** Kelurahan Rawajati.

## Menjalankan

```bash
cd frontend
npm install
npm start
```

Buka `http://localhost:4200`. Klik **Reset Data Demo** setelah update agar seed terbaru termuat.

## Masuk cepat (3 peran)

| Peran | Hasil |
|:---|:---|
| **Lurah / Kasi Ekbang & Kesra** | Tab Kesra (PSN/ABJ) + Tab Ekbang (foto kerja & gudang PPSU) |
| **Kader Jumantik RT** | Input Jumat pagi & laporan PSN |
| **Anggota / Petugas PPSU Lapangan** | Lapor kerja Non-CRM + pinjam/kembalikan alat |
